# 🎓 Student Management System

A Python-based desktop application integrated with a MySQL database to manage student records, courses, and administrative tasks.

## Features
- **Student Operations**: Add, update, view, and delete student details.
- **Database Integration**: Relational mapping using MySQL.
- **Structural Design**: Includes database schemas and class structures for Admin, Teacher, and Student roles.

## Requirements
- Python 3.x
- MySQL Server
- `mysql-connector-python` package
